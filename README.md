# ДЭ 2027 · Оператор технической поддержки

КИМ 09.01.05-1-2027. «Универсальный» — учебный вариант трёх инвариантных заданий по образцу КИМ на с. 31–36. Профильный экзамен включает инвариантную и вариативную части. Содержание вариативной части определяет образовательная организация.

Для локального просмотра запустите из каталога проекта `python -m http.server 4187 --bind 127.0.0.1` и откройте [страницу сайта](http://127.0.0.1:4187/). Раздел «Примеры» содержит заполненный реестр, ответы, технологические карты, SQL-файлы и отчёты. Тренировка и пробный экзамен охватывают инвариантную часть, для которой предусмотрено 180 минут и 75 баллов.

В пробном экзамене 30 вариантов с названиями по темам обращений. В каждом из них изменены три заявки относительно учебного образца «Универсальный». Варианты также задают контрольную запись и роль для проверки в СУБД, а для разбора диагностики содержат учебные журналы, автозагрузку и замеры. На рабочем месте используйте выданный номер и соберите собственные подтверждения. Заявки можно прочитать на странице или скачать в CSV.

Запускайте `examples/setup.sql` в `psql` от администратора на отдельном экземпляре PostgreSQL. Если предыдущий запуск прервался сразу после создания пустой базы, используйте `-v resume=on` только для этой базы. Существующие учебные роли или объекты в базе останавливают настройку.
