# ДЭ 2027 · Оператор технической поддержки

КИМ 09.01.05-1-2027. «Универсальный» — учебный вариант трёх инвариантных заданий по образцу КИМ на с. 31–36. Вариативная часть ожидает исходных данных.

Откройте `index.html` для локального просмотра. Раздел «Примеры» содержит заполненный реестр, ответы, технологические карты, сценарий PostgreSQL с проверкой прав и пример отчёта о диагностике. Тренировка и пробный экзамен рассчитаны на 180 минут инвариантной части. Подробности профильного экзамена приведены на главном экране и в КИМ.

Оболочка сайта, стили и иллюстрации перенесены из [ДЭ 2027 · Программист](https://github.com/OlgaKraven/2027-prog-demo). Планируемый адрес — [2027-vdko-demo](https://olgakraven.github.io/2027-vdko-demo/).
