Отчёт о настройке SQL Server и Windows

Пример для места 07. Таблица, операции и восстановление проверены в SQL Server Express LocalDB. Для учебного маршрута с SSMS и DBeaver заполните параметры сетевого экземпляра по своей ВМ.

Windows и итоговая проверка

На учебной ВМ проверьте TCP-порт и запущенную службу. В отчёт приложите данные подключения под client03, вывод icacls для sql_reports_07, подтверждения чтения и запрета записи, значение DB_HOME для dbadmin_07 и снимок ВМ либо точку восстановления.

Если вход через DBeaver отклонён, проверьте режим аутентификации, наличие логина и сопоставление логина с пользователем в corpdata_07. После исправления сначала подтвердите имя пользователя и базы, затем повторите SELECT.
