Заполненный учебный пример. События, показатели и выводы ниже иллюстрируют оформление. Для сдачи нужны данные вашего стенда.

Открыть разбор фактических данных Windows с приложениями

Сведения о системе

Место 07, учебная ВМ Windows 11, 4 виртуальных ядра, 8 ГБ ОЗУ, диск 80 ГБ. Источник сведений на стенде — systeminfo или dxdiag.

На стенде примените фильтр журнала System или Application за 48 часов, уровни 1 и 2, сохраните три записи со временем, источником и текстом. Приложите снимки или EVTX.

Get-WinEvent -FilterHashtable @{
  LogName = 'System', 'Application'
  StartTime = (Get-Date).AddHours(-48)
  Level = 1,2
} | Select-Object TimeCreated, LogName, Id, ProviderName, LevelDisplayName, Message

Автозагрузка и безопасность

  • OneDrive — нужен только при использовании корпоративной синхронизации. В примере оставить до согласования.
  • Teams — запуск при входе необязателен, если пользователю достаточно ручного запуска.
  • Утилита обновления PDF-редактора — сначала проверить, кто отвечает за обновления и применяются ли они без автозапуска.

Пример результата быстрой проверки Microsoft Defender — угроз не найдено. Снимок результата сохраняется в SecurityScan_07. Если есть обнаружения, укажите тип угрозы, действие защиты и статус проверки.

Нагрузка и приоритеты

Интервал наблюдения — 2 минуты. Учебные показатели: CPU 28%, память 68%, диск до 65% активности, сетевой обмен до 1,4 Мбит/с. Основные потребители — редактор (1,1 ГБ), браузер (1,4 ГБ), Defender (кратковременная нагрузка CPU и диска). У наблюдаемых процессов штатные приоритеты.
