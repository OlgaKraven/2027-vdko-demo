Отчёт о настройке PostgreSQL и Windows

Образец для места 07. Параметры установки, настройки Windows и подтверждения для сдачи берите со своего стенда.

Результат прогона PostgreSQL

PostgreSQL 18.1, экземпляр lab_sql_07, адрес 127.0.0.1:15476. В corpdata_07.public.clients сохранены две записи: 1 — a@example.test и 2 — b@example.test. Под client03 SELECT вернул обе записи. Сервер отклонил UPDATE с кодом 42501. Под client01 INSERT вернул id 3, после ROLLBACK число пробных строк равно 0.

Выгрузка clients.sql содержит CREATE TABLE и две исходные строки. После восстановления в отдельной базе SELECT вернул id 1 и 2.

Установка и совместимость

В командах ниже указан стандартный порт 5432. Если на стенде выбран другой порт, подставьте его во все команды и подключения. В конфигурации экземпляра задайте cluster_name = 'lab_sql_07' и перезапустите службу. В отчёт перенесите фактическое имя службы, путь установки и каталог данных. Проверьте свободный порт перед установкой, запущенную службу и версию через SELECT version(). Название подключения в DBeaver задайте lab_sql_07.

База, роли и экспорт

Из каталога примеров выполните psql -X -h 127.0.0.1 -p 5432 -U postgres -d postgres -v seat=07 -f setup.sql на чистом учебном сервере. Если утилиты отсутствуют в PATH, укажите полный путь к psql.exe и pg_dump.exe из папки bin установленного PostgreSQL. Задайте пароли пяти ролям командой \password в psql. В DBeaver создайте отдельные подключения с этими логинами. Запрос SELECT current_user, current_database(); подтверждает контекст.

Если предыдущий запуск прервался после создания вашей пустой corpdata_07, добавьте к команде -v resume=on. Если на экземпляре уже есть учебные роли другого места, подготовьте отдельный экземпляр или восстановите чистый снимок.

Учётные записи и права Windows

  1. Создайте локальную учётную запись dbadmin_07 и рабочий каталог C:\DBAdmin_07. Дайте этой учётной записи права на её рабочую папку.
  2. Войдите под dbadmin_07. Через переменные среды для пользователя задайте DB_HOME со значением пути установки PostgreSQL. В новом окне PowerShell проверьте $env:DB_HOME.
  3. Для доступа к папке нужна отдельная учётная запись Windows client03. Создайте её на стенде без включения в группу администраторов. Создайте sql_reports_07 на рабочем столе по условию и проверьте, что проверяющий пользователь может пройти к папке. В дополнительных параметрах безопасности отключите наследование, оставьте SYSTEM и «Администраторы» с полным доступом, добавьте client03 право «Чтение и выполнение», удалите широкие записи с правом изменения.
  4. Сохраните вывод icacls для папки. Под client03 откройте тестовый файл, затем проверьте отказ при создании нового файла. Сделайте снимок ВМ после настройки.

Доказательства для сдачи

Включите снимки установки, создания таблицы, матрицы прав и подключения из DBeaver. Отдельно приложите ACL, подтверждение снимка ВМ, вывод проверки зависимостей, служб и порта. Если порт занят, определите процесс-владелец и укажите согласованный порт в отчёте и настройках клиента.
