Отчёт о настройке MySQL и Windows

Пример для места 07. Разделы о сервере, данных и правах заполнены по учебному прогону MySQL. Настройка Windows ниже показывает, какие подтверждения собрать на своей ВМ.

Сервер и подключение

ПараметрЗначение на стенде
СерверMySQL Community Server 8.4.13, отдельная сборка Windows x64
Подключение127.0.0.1:15478, база corpdata_07, TCP
ФайлыКаталог стенда mysql-8.4.13-winx64 и отдельный каталог данных mysql-review-1211
ЗапускОтдельный процесс mysqld.exe. В варианте с установкой службы указать фактическое имя, например lab_sql_07.

На стенде порт 15478 принял TCP-подключение. В маршруте Workbench используйте порт своей установки, проверьте его кнопкой Test Connection, затем выполните SHOW VARIABLES WHERE Variable_name IN ('basedir','datadir','port'); и перенесите значения в таблицу.

Таблица и права

Создана corpdata_07.clients с движком InnoDB. Поле id — первичный ключ с AUTO_INCREMENT. Поля name и email имеют тип VARCHAR, поле reg_date — DATE.

Windows и итоговая проверка

На экзаменационной ВМ укажите рабочий каталог C:\DBAdmin_07, значение пользовательской переменной DB_HOME и путь к sql_reports_07. Приложите вывод icacls, чтение файла под client03 и отказ при создании пробного файла. Сохраните снимок ВМ или точку восстановления.

Если Test Connection возвращает отказ, сравните порт в настройках клиента с @@port и статусом процесса или службы. При ошибке доступа после подключения сопоставьте аккаунт с CURRENT_USER() и SHOW GRANTS.
