0. Установка и настройка программ

Рабочее место для тренировки

  1. В Windows проверьте, что открываются «Просмотр событий», «Диспетчер задач» и «Безопасность Windows». Для заявки создайте тестовую запись в учебной системе колледжа или попросите доступ к стенду GLPI. Для домашнего просмотра материалов достаточно браузера.
  2. Установите офисный пакет, если его ещё нет. На странице LibreOffice выберите установщик Windows x86-64. В Writer откройте и сохраните DOCX, в Calc — XLSX. Если на площадке используются Word и Excel или Р7-Офис, тренируйтесь в доступных редакторах.
  3. Для задания 2 установите одну из трёх СУБД. Сверьте выбранный маршрут с рабочим местом площадки. Архив содержит отдельную выгрузку для каждой СУБД, команды идут в PowerShell.

PostgreSQL и pgAdmin

Скачайте PostgreSQL для Windows. По ссылке Download the installer выберите Windows x86-64. Оставьте PostgreSQL Server, pgAdmin 4 и Command Line Tools. Запишите пароль postgres и порт, обычно 5432. Создайте пустую базу de_check. Из распакованной папки выполните команды, подставив адрес, порт и путь из своей установки.

& 'C:\Program Files\PostgreSQL\18\bin\psql.exe' -h localhost -p 5432 -U postgres -d de_check -v ON_ERROR_STOP=1 -f .\examples\clients.sql
& 'C:\Program Files\PostgreSQL\18\bin\psql.exe' -h localhost -p 5432 -U postgres -d de_check -c 'SELECT COUNT(*) FROM public.clients;'

MySQL и Workbench

Скачайте MySQL Server 8.4 LTS MSI для Windows и MySQL Workbench. В MySQL Configurator выберите локальную службу, задайте пароль root и запишите порт, обычно 3306. Подключитесь в Workbench и создайте пустую базу de_check. Из распакованной папки откройте клиент.

& 'C:\Program Files\MySQL\MySQL Server 8.4\bin\mysql.exe' -h localhost -P 3306 -u root -p de_check

Введите пароль, затем выполните в клиенте:

SOURCE examples/clients-mysql.sql
SELECT COUNT(*) FROM clients;

SQL Server и SSMS

Скачайте SQL Server Express и установите Database Engine. Запишите имя экземпляра, например SQLEXPRESS. Установите SSMS и при работе через терминал sqlcmd. В SSMS подключитесь к .\SQLEXPRESS через Windows Authentication и создайте пустую базу de_check. Для локального стенда со штатным самоподписанным сертификатом выполните:

sqlcmd -S '.\SQLEXPRESS' -E -C -b -d de_check -i .\examples\clients-sqlserver.sql
sqlcmd -S '.\SQLEXPRESS' -E -C -b -d de_check -Q 'SELECT COUNT(*) FROM dbo.clients;'

После импорта каждый запрос должен вернуть 2. Для прогона прав доступа выполните отдельные шаги своего маршрута. В комплекте отчётов нет проекта для разработки, поэтому SDK .NET и пакеты NuGet не требуются.
