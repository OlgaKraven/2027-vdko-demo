0. Установка и настройка программ

Рабочее место для тренировки

  1. В Windows проверьте, что открываются «Просмотр событий», «Диспетчер задач» и «Безопасность Windows». Для заявки создайте тестовую запись в учебной системе колледжа или попросите доступ к стенду GLPI. Для домашнего просмотра материалов достаточно браузера.
  2. Установите офисный пакет, если его ещё нет. На странице LibreOffice выберите установщик Windows x86-64. В Writer откройте и сохраните DOCX, в Calc — XLSX. Если на площадке используются Word и Excel или Р7-Офис, тренируйтесь в доступных редакторах.
  3. Для задания 2 установите одну из трёх СУБД. Сверьте выбранный маршрут с рабочим местом площадки. Таблицу и записи создайте запросами из задания 2.

PostgreSQL и pgAdmin

Скачайте PostgreSQL для Windows. По ссылке Download the installer выберите Windows x86-64. Оставьте PostgreSQL Server, pgAdmin 4 и Command Line Tools. Запишите пароль postgres и порт, обычно 5432. Создайте пустую базу de_check. Для задания 2 создайте учебную базу по шагам своего маршрута. Открывайте Query Tool в выбранной базе.

MySQL и Workbench

Скачайте MySQL Server 8.4 LTS MSI для Windows и MySQL Workbench. В MySQL Configurator выберите локальную службу, задайте пароль root и запишите порт, обычно 3306. Подключитесь в Workbench и создайте пустую базу de_check. В Workbench откройте SQL Editor для этого подключения.

SQL Server и SSMS

Скачайте SQL Server Express и установите Database Engine. Запишите имя экземпляра, например SQLEXPRESS. Установите SSMS и при работе через терминал sqlcmd. В SSMS подключитесь к .\SQLEXPRESS через Windows Authentication. Создайте учебную базу по заданию 2 и выберите её в окне запроса.

В задании 2 выберите карточку для вашей СУБД. Она задаёт порядок создания таблицы, ввода записей и проверки прав.

ЧаВО об экзамене

Какие задания разобраны?

Три инвариантных задания образца КИМ 09.01.05-1-2027 на с. 31–36. Для профильного экзамена состав вариативной части уточните у колледжа.

Будет ли интернет?

На с. 23 КИМ предусмотрен доступ к профильным справочникам и сервисам по белому списку. Уточните его на инструктаже. Для домашней репетиции заранее скачайте материалы и проверьте, что редакторы, локальная база и архив открываются без внешней сети.

Можно ли взять USB-накопитель или готовый отчёт?

Учебный комплект используйте дома. На экзамене работайте с файлами, носителями, учётными записями и ресурсами, которые разрешила площадка. Заранее уточните папку сдачи и допустимые форматы.

Что делать, если пропал доступ или завис компьютер?

Сообщите эксперту номер места, действие и текст ошибки. Дождитесь указаний по продолжению. Требования к работе с оборудованием приведены на с. 24 КИМ.

Какие подтверждения сохранить?

Для реестра сохраните записи и номера карточек, для базы — отчёт и SQL с двумя строками, для диагностики — отчёт со своими снимками или выгрузками. До сдачи откройте сохранённые файлы.
