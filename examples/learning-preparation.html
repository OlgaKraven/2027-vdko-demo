0. Установка и настройка программ

Рабочее место для тренировки

  1. В Windows откройте «Параметры → Система → О системе» и посмотрите «Тип системы». На обычном 64-разрядном ПК выбирайте Windows x86-64 или x64. Для Windows на ARM сверьте поддержку серверной программы с площадкой.
  2. Сохраните установщики и драйверы в отдельной папке до отключения интернета. Проверьте, что запускаются офисные редакторы, графический клиент и локальный сервер выбранной СУБД.
  3. Для задания 3 откройте «Просмотр событий», «Диспетчер задач» и «Безопасность Windows» или разрешённый антивирус. Эти средства Windows скачивать отдельно не нужно.

Задание 1. Офисные редакторы и система заявок

Используйте один комплект. Пустая книга должна сохраняться в XLSX или ODS, а документ — в DOCX или ODT.

  • LibreOffice. Нажмите Download, выберите Windows x86-64, скачайте MSI и запустите «Обычная установка». Проверьте запуск Calc и Writer.
  • Word и Excel. С выданной учётной записью Microsoft 365 используйте Install apps → Microsoft 365 apps. Загрузите программы и проверьте активацию, пока есть сеть. На компьютере колледжа проверьте, что приложения уже открываются.
  • Р7-Офис. Найдите настольные редакторы для Windows, скачайте установщик нужной разрядности и запустите его. Проверьте редактор таблиц и редактор документов.

Учебный GLPI

Откройте в браузере адрес учебной системы заявок, который выдал преподаватель, и войдите с учебной учётной записью. Проверьте, что доступны «Поддержка → Заявки → Добавить» и поле категории. Если GLPI работает на сервере колледжа, ПК должен иметь доступ к нему по локальной сети.

Для своего локального стенда понадобится Docker Desktop с WSL 2. На странице продукта скачайте вариант Windows AMD64, установите Docker Desktop и запустите движок. Ход развертывания GLPI и получение образов GLPI и MariaDB до отключения сети описаны в официальном руководстве. Docker Desktop · GLPI в Docker.

Задание 2. Сервер и графический редактор

Выберите одну СУБД по оснащению площадки. Таблицу и строки создадите в её графическом редакторе в задании 2. DBeaver нужен для отдельного подключения под учебной учётной записью.

PostgreSQL и pgAdmin

  1. На странице PostgreSQL для Windows нажмите Download the installer. В таблице EDB выберите PostgreSQL 18 и Windows x86-64. Сохраните EXE.
  2. Запустите EXE. Оставьте PostgreSQL Server, pgAdmin 4 и Command Line Tools. Запишите выбранный каталог данных, пароль пользователя postgres и порт. Обычно это 5432. Stack Builder для упражнения не нужен.
  3. Откройте pgAdmin 4. При регистрации сервера укажите 127.0.0.1, ваш порт, базу postgres и пользователя postgres. Откройте Databases и убедитесь, что подключение работает.

Сохраните postgresql-*.jar из раздела Java 8 / JDBC 4.2. Этот файл подходит и для Java, входящей в актуальный DBeaver. Драйвер PostgreSQL JDBC.

MySQL и Workbench

  1. На странице MySQL Community Server 8.4 LTS выберите Microsoft Windows и Windows (x86, 64-bit), MSI Installer. На промежуточном экране нажмите No thanks, just start my download.
  2. Отдельно скачайте MSI на странице MySQL Workbench для Windows. Если установщик просит Microsoft Visual C++ Redistributable, сохраните x64-пакет со страницы Microsoft и установите его первым. Microsoft Visual C++ Redistributable.
  3. После установки сервера откройте MySQL Configurator. Включите TCP/IP, укажите порт, обычно 3306, задайте пароль root и настройте службу lab_sql_07 для места 07. Примените конфигурацию.
  4. Установите Workbench. У MySQL Connections нажмите «+», выберите Standard TCP/IP и введите 127.0.0.1, свой порт и имя root. Нажмите Test Connection.

На странице Connector/J выберите Platform Independent → ZIP Archive. Из ZIP извлеките mysql-connector-j-*.jar. Драйвер MySQL Connector/J.

SQL Server Express и SSMS

  1. На странице SQL Server найдите Express и нажмите Download now. Чтобы подготовить полный установщик, в загрузчике выберите Download Media, затем пакет Express Core и папку загрузки.
  2. Запустите полученный пакет. Выберите New SQL Server stand-alone installation и компонент Database Engine Services. Укажите именованный экземпляр LAB_SQL_07 для места 07. На Database Engine Configuration выберите Mixed Mode, добавьте себя в администраторы и задайте пароль sa. Администратор подключается через Windows Authentication, учебные логины используют SQL Server Authentication.
  3. На странице установки SSMS выберите Download SQL Server Management Studio 22 installer. Запустите vs_SSMS.exe и установите базовый компонент SSMS под администратором Windows. Для переноса установки без интернета заранее создайте локальный layout по инструкции Microsoft. Офлайн-установка SSMS.
  4. В SSMS откройте Connect → Database Engine. Укажите .\LAB_SQL_07 и Windows Authentication. Порт TCP настройте по первой карточке маршрута SQL Server.

Скачайте JDBC Driver ZIP и извлеките из него mssql-jdbc-*.jre11.jar. Этот вариант работает с Java 11 и новее. Драйвер Microsoft JDBC.

Подключение из DBeaver без интернета

  1. На странице DBeaver Community выберите Windows и EXE или ZIP нужной архитектуры. EXE установите. ZIP распакуйте целиком и откройте dbeaver.exe.
  2. В DBeaver откройте Database → Driver Manager. Выберите стандартный драйвер своей СУБД и нажмите Edit → Libraries → Add File. Укажите заранее скачанный JAR.
  3. Сохраните лицензию из пакета драйвера рядом с JAR. В учебном профиле замените ссылки Maven с пометкой RELEASE локальным JAR. Если в списке осталась отдельная ссылка HTTPS на текст лицензии и DBeaver пытается её загрузить, сохраните текст заранее и удалите сетевую ссылку из списка. Встроенные записи лицензий оставьте. Нажмите OK.
  4. Когда в задании появится учебный пользователь, создайте отдельное соединение. Укажите 127.0.0.1, свой порт, базу corpdata_07 и заданные имя и пароль. В PostgreSQL выбирайте стандартный драйвер PostgreSQL. Проверьте Test Connection без сети и откройте таблицу clients.
